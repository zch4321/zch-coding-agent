# v0.3.1

从 v0.3.0 升级时，应用会自动迁移配置和数据库。应用自有的文件 Diff 与恢复功能已移除，文件恢复改为依赖用户自己的 Git 历史、stash 或其他备份；升级前如需保留旧的应用内变更记录，请先查看并自行保存。

## 升级说明

- SQLite 自动迁移到 v13，保留已有 Project、Session 和消息。迁移会删除旧 `file_changes`、恢复快照和 retention 状态，并加入项目产物元数据；使用过历史分叉 migration 11 的开发数据库也按已知 checksum 兼容，无需手工删除或重建数据库。
- AppConfig 自动迁移到 v26，删除已退役的 Diff 限制与 `create_file` 授权规则，保留其他 Provider、权限和运行配置。
- 模型文件工具由 `create_file` 改为 `write_file`，支持创建和整体覆盖文件。旧对话中的 `create_file` 调用仍可阅读，旧授权不会自动扩大为覆盖写权限。
- Headless result 升为 schema v2，不再返回 `patchPath/patchStatus`，也不生成 `workspace.patch`。依赖这些输出的调用方需要改为检查工作树或 Git。
- 当前桌面安装包仍为未签名的 Windows x64 构建，Windows SmartScreen 可能显示提示。

## 文件操作与 Git Review

- 右侧 Diff 页签改为项目级实时 Git Review，支持查看相对 `HEAD`、未暂存、已暂存和 merge-base 的变化，并选择本地或远程分支作为比较基准。
- `write_file` 自动创建缺失的父目录，覆盖文件时保留原文件权限；`apply_patch` 基于执行时的最新内容精确匹配，遇到缺失或歧义时保持文件不变并要求重新读取。
- `delete_file` 无需读取文件内容即可删除大二进制文件，重复删除返回成功的无操作结果。
- 文件审批展示工具、完整参数、原因和风险信号；Session rewind、retry、edit 和 fork 只调整对话，不再回滚工作树文件。
- 同项目可以并发运行多个任务和可写 Agent；并发文件写入采用最后一次写入生效的语义。

## 后台任务与项目产物

- Background 面板统一展示 Subagent、Swarm 和 Terminal，支持停止顶层任务、单个 Swarm child 或终端，并预览终端日志。终端预览支持暂停和恢复跟随、复制文本及读取最终输出。
- 后台 Agent 与终端有独立生命周期，父 Run 完成或中断后仍可继续运行。归档或删除会话、删除项目及退出应用时，会协调取消相关后台任务并等待收尾。
- 同项目的任务共享短路径的原生 `workspace/tmp` 入口；命令、文件工具、终端和任务清单引用同一组地址，完整输出按项目及类型分配持久编号。
- 已有输出通过登记、复制和校验迁移，兼容旧原生地址及工具 alias；有歧义的 fork 旧路径会要求提供明确的原生路径。
- 已完成捕获按各自完成时间保留 24 小时。活动捕获不会提前回收，其他任务活动也不会延长已完成产物的保留期限。
- Desktop 与 Headless 共用 profile 的 `agent.db`，支持 `--profile-dir` 和 `ZCH_PROFILE_DIR`。同一 profile 支持轮流使用，被占用时返回 `PROFILE_IN_USE`；Headless 本次运行配置不会改写 Desktop 设置，导出索引只列当前任务产物。

## 对话、Provider 与稳定性

- 支持继续用户中断或可恢复 Provider 失败后的对话，复用已提交历史，不重复添加用户消息。
- 对临时网络、超时、限流和部分服务端错误进行有界自动重试，并显示重试活动；用户取消、余额不足和上下文超限等情况不会按临时网络错误重试。
- 完善 MiMo 专用协议适配和模型能力过滤，支持 Anthropic prompt caching，并修正工具 schema 与请求控制参数的协议转换。
- 新增后端运行日志与诊断信息，改进请求控制参数记录、旧 trace 兼容、模型角色选择展示和输入框上方的 Todo 布局。
- 修复跨 Run 的 prompt context 刷新和 Swarm 工具可用性、自动标题限制、后台取消收尾，以及 CommonJS 原子写入依赖被内联后造成的启动失败。
- 开发文档新增 Code map，并将文档链接和标题检查纳入日常检查与完整发布门禁。

## 已知限制

- 非 Git 项目没有 Diff 内容或应用级文件恢复能力；未跟踪文件需要加入 Git 后才能查看标准 Git Diff，二进制仅显示变更标记。
- Git Review 展示项目范围内来自用户、Agent、Terminal 和外部程序的混合变化，不按会话或执行者归因。
- 并发写入可能覆盖其他任务的改动；需要隔离时请使用 Git branch/worktree 或外部协调。
- 任务输出没有磁盘配额，终端进程不会从日志恢复。Shell 仍以宿主权限运行，项目临时目录不是操作系统沙箱。
- Swarm child 仍不支持递归委派或继续追问；自定义 Shell profile、WSL adapter、对话 Markdown 搜索投影以及 ProjectModel/Serena/code intelligence 尚未开放。
