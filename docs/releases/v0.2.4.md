# v0.2.4

本版本完成 Durable Backend 切换，并统一了桌面端的持久化、恢复、诊断与交互路径。

## 升级说明

- 对话、消息、运行状态和文件变更审计现已统一使用 SQLite Durable Backend。
- 旧 `workbench.json`、`change-history.json` 和 renderer 本地对话数据不会迁移或读取。
- Durable Session 格式尚在重新设计，Markdown Session 导入和导出暂时禁用；
  Trace transcript 导出仍可使用。
- 回退只修改对话历史，不会撤销已经发生的文件、终端或外部工具副作用。

## 主要更新

- 支持重试和编辑原始用户消息、回退历史及分叉 Durable Session，不会重复追加
  user turn。
- 支持归档对话，并可在设置页恢复或永久删除已归档 Session。
- 无需重启应用即可为现有 Session 开启或关闭分段 Trace 记录。
- 运行警告和错误改用有界的 Naive UI Message 呈现。
- Desktop 和 Headless 入口现在共用同一套 Durable Runtime。
- 文件浏览器改为资源树与单文件预览，并支持使用系统默认应用打开文件。

## 稳定性与安全

- 加强 SQLite 事务、迁移、保留量统计、生命周期释放、请求去重和并发 Session 所有权。
- 加强 Workspace 路径守卫、IPC 校验、错误脱敏、Provider 流处理和文件变更回退边界。
- 改进 Windows 终端输入、native 依赖检查、打包后 SQLite 验证及 Electron 端到端覆盖。
- 统一 Naive UI 主题、对话框、状态标识、表单、侧栏和通知交互。

## 已知限制

- 旧版对话文件会保持原样，但无法通过 Durable Session 界面打开。
- Session 回退无法撤销已经发生在对话历史之外的副作用。
