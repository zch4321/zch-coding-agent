# v0.2.5

本版本加入更多 Provider 协议、只读 Subagent 与有序并发工具执行，并重新整理了对话时间线和运行状态界面。

## 升级说明

- `v0.2.4` 的应用配置会自动迁移到 AppConfig v14；已有 Provider、凭据引用、模型覆盖和自定义限制会保留。SQLite 会自动迁移到 v5，现有 Session 和消息无需手工转换。
- ProjectModel、Serena 和 `project_*` / `code_*` 工具暂时停用，应用不会读取、创建或改写工作区中的 `.zch/project-model.json`。普通文件浏览和其他工作区工具不受影响。
- 旧会话仍可查看、导出和删除；如果当前活动历史中包含 `v0.2.4` 的旧格式工具结果，新运行会在发起 Provider 请求前停止，而不会猜测或改写历史。可以新建会话，或回退到旧工具结果之前继续。
- Subagent 默认关闭，可在“设置 → Agents”中启用。Subagent 直接读取实时工作区，不再创建 Git checkpoint 或目录快照。

## 主要更新

- 新增 Generic Responses 和 Generic Anthropic Messages Provider，并保留 DeepSeek 与 Generic Chat Completions。
- Provider 设置支持模型选择、每模型最大上下文、压缩阈值、最大输出长度，以及关闭 / 高 / 最大思考深度。
- 新增只读 `subagent_run`。主 Agent 可委派自包含调查任务，多个 Subagent 可并发执行，并在右侧 Agents 面板查看状态、耗时、工具调用数、Token 用量和最终消息。
- 工具执行改为有序并发：连续的并行工具可以重叠执行，写入、MCP 执行、终端和未知工具保持串行屏障；审批和结果始终按原始 call 顺序提交。
- 对话时间线按用户轮次展示为“用户消息 → 工具调用 → 思考过程 → Agent 消息”，工具与明文 reasoning 默认折叠，加密 reasoning 不进入界面。
- 工具结果使用统一、受限的模型上下文投影，避免展示内容、模型输入和内部元数据彼此漂移。

## 界面与稳定性

- 新增 Agents 侧栏历史回看；隐藏的 child Session 不进入普通会话列表或主消息时间线。
- 应用自有滚动区域统一使用 Naive UI `NScrollbar`，滚动条出现或消失时不再挤动内容。
- 修复 Agent 分段消息重复显示操作按钮、完成后残留“生成中”、Reasoning 与工具调用错位，以及 xterm 内容越出终端面板的问题。
- 改进 Provider 模型发现、独立审批模型配置、运行限制表单、工具结果截断和 Windows 终端布局。
- 移除不再集成到产品发布流程的 Benchmark CLI、Docker Worker 和内置数据集代码。

## 已知限制

- Subagent 当前仅支持只读、单次、自包含任务；尚不支持递归委派、继续追问、模型池、Swarm、取消按钮或自定义 child 工具列表。
- Subagent 与主 Agent 观察同一个实时工作区，不提供冻结时点的一致性；同批 `run_command` 也可能改变其读取结果。
- ProjectModel、Serena 和代码智能将在完成 Swarm 后迁移到 SQLite 并重新启用。
- 当前桌面安装包仍以未签名的 Windows x64 版本发布，Windows SmartScreen 可能显示提示。
