条件允许时，先使用父 Agent 的命令工具执行可共享的相关验证，再调用 `swarm_run`。把命令、退出码和精简后的关键输出放入 `sharedContext`；如果无法运行验证，也要在其中明确说明。

把公共背景、证据、约束和输出要求放入 `sharedContext`，每项 task 只描述当前 Child 的具体职责。两部分合起来必须自包含，因为子 Agent 不会收到父对话历史。

为每项 task 显式设置 `toolAccess`：调查任务使用 `readonly`；只有当 Child 必须使用父 Run 的非只读工具和权限模式时才使用 `inherit`。对于可写任务，条件允许时为它们分配互不重叠的文件或子系统。同一 Run 下的独立 Swarm Job 可以并发执行。按任务需要选择 Agent 数量；只有独立交叉验证确有价值时才增加副本。分配器会优先轮换合格模型，但模型池不足时仍可能复用同一模型。为每项任务选择足够使用的最低能力等级。
